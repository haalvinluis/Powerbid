# Shared Package & Data Contracts

This directory contains cross-boundary documentation, type definitions, data contracts, and datasets shared across the Flutter mobile app and Node.js backend server.

## Contents

- Data Contracts (Socket.IO event payloads, DTOs)
- Category Datasets (Cricket 800 players catalog, Naruto 250 characters catalog)
- Game Rules & Config Constants (Room player limits, timer values, default budgets)
